Ters Polonya Gösterimi (RPN): Matematiksel İfadelerde Minimalizm ve Güç


Ters Polonya Gösterimi (RPN), işleçlerin operandlardan sonra yazıldığı bir matematiksel notasyon türüdür. Geleneksel infix gösteriminden farklı olarak parantez kullanımını tamamen ortadan kaldırır ve işlem sırasını yığıt (stack) tabanlı bir sistemle yönetir. Bu yazıda, RPN’nin kısa tarihçesinden, Python’da trigonometrik ve karekök fonksiyonlarını destekleyen bir RPN hesaplayıcı uygulamasından bahsedeceğiz.


RPN’nin Kısa Tarihçesi


RPN, Polonyalı mantıkçı Jan Łukasiewicz tarafından 1920’lerde geliştirilmiştir. İlk haliyle “Polonya Notasyonu” olarak bilinen bu yöntem, işleçleri operandlardan önce yazıyordu. Daha sonra, tersine çevrilmiş hali olan RPN, Amerikalı bilgisayar bilimci Charles L. Hamblin tarafından bilgisayar hesaplamalarında kullanılmak üzere geliştirildi.


1960’lı yıllarda, Hewlett-Packard (HP) şirketi RPN’yi mühendislik hesap makinelerinde kullanmaya başladı. RPN’nin sağladığı parantezsiz hesaplama ve yığıt tabanlı yaklaşım, HP hesap makinelerinin mühendisler ve bilim insanları arasında popüler olmasını sağladı.


Python ile RPN Hesaplayıcı


Aşağıdaki Python kodu, RPN hesaplamalarını trigonometrik fonksiyonlar ve karekök işlemleri ile genişletir. Bu sayede, yalnızca temel aritmetik değil, daha karmaşık matematiksel ifadeleri de değerlendirebilirsiniz.


Kod:


import math


def evaluate_rpn(expression):

    tokens = expression.split()

    stack = []

    

    for token in tokens:

        if token.isdigit():

            stack.append(int(token))

        else:

            if token == '+':

                right_operand = stack.pop()

                left_operand = stack.pop()

                result = left_operand + right_operand

            elif token == '-':

                right_operand = stack.pop()

                left_operand = stack.pop()

                result = left_operand - right_operand

            elif token == '*':

                right_operand = stack.pop()

                left_operand = stack.pop()

                result = left_operand * right_operand

            elif token == '/':

                right_operand = stack.pop()

                left_operand = stack.pop()

                if right_operand == 0:

                    raise ValueError("Division by zero")

                result = left_operand / right_operand

            elif token in ['sin', 'cos', 'tan', 'atan']:

                operand = stack.pop()

                if token == 'sin':

                    result = math.sin(math.radians(operand))

                elif token == 'cos':

                    result = math.cos(math.radians(operand))

                elif token == 'tan':

                    result = math.tan(math.radians(operand))

                elif token == 'atan':

                    result = math.atan(math.radians(operand))

            elif token == 'sqrt':

                operand = stack.pop()

                if operand < 0:

                    raise ValueError("Square root of a negative number")

                result = math.sqrt(operand)

            else:

                raise ValueError(f"Unknown operator: {token}")

            

            stack.append(result)

    

    return stack.pop()


# Örnek kullanım

expressions = [

    "3 4 + 2 * sin",

    "5 1 2 + 4 * + 3 -",

    "90 cos",

    "8 4 / 2 3 * -",

    "-4 sqrt"  # Negatif sayı kontrolü

]


for expr in expressions:

    try:

        print(f"{expr} -> {evaluate_rpn(expr)}")

    except ValueError as e:

        print(f"Hata: {e}")


Kodun Çalışma Mantığı

1. Token’lar Ayrıştırılır: RPN ifadesi boşluk karakteri ile ayrıştırılır.

2. Yığıt Yönetimi:

• Sayılar doğrudan yığıta eklenir.

• İşleçler geldiğinde, yığıttan gerekli operandlar alınır ve işlem sonucu tekrar yığıta eklenir.

3. Fonksiyonlar: Trigonometrik fonksiyonlar ve karekök işlemleri math modülü aracılığıyla gerçekleştirilir.


Örnek Çıktılar

1. Girdi: 3 4 + 2 * sin

Sonuç: 0.9876883405951378

(Toplam 7, ikiyle çarp 14, ardından sinüs fonksiyonu uygulanır.)

2. Girdi: 5 1 2 + 4 * + 3 -

Sonuç: 14

3. Girdi: 90 cos

Sonuç: ~0.0

(90 derece kosinüsü sıfırdır.)

4. Girdi: -4 sqrt

Hata: Square root of a negative number


Sonuç


RPN, matematiksel işlemleri basitleştirmek ve hesaplama hatalarını en aza indirmek için güçlü bir araçtır. Python gibi dillerde kolayca uygulanabilmesi, bu yöntemi hem eğitim hem de pratik uygulamalar için cazip kılar. Trigonometrik ve özel fonksiyonlarla genişletilen bir RPN hesaplayıcı, mühendislik ve bilimsel projelerde faydalı bir araç olabilir.
