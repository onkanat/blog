OpenAI Tool Call Kullanımı – İlk Deneyimim


Bu yazıda, OpenAI’nin tool call özelliğini kullanarak nasıl yerel bir LLM (Large Language Model) ile fonksiyon çağrısı yapılabileceğini anlatacağım. Özellikle LM Studio gibi bir yerel LLM altyapısı ile nasıl etkileşime geçildiğini gösteren basit bir örnek sunuyorum.


Aşağıdaki kod, bir kullanıcının sipariş teslimat tarihini öğrenmek istediği durumda, LLM’nin get_delivery_date adlı bir fonksiyonu çağırmasını sağlamaktadır.

📦 Kod: Tool Call Örneği

from datetime import datetime, timedelta
import json
import random
from openai import OpenAI

# Yerel LLM sunucusuna bağlantı
client = OpenAI(base_url="http://localhost:1234/v1", api_key="lm-studio")
model = "qwen2.5-coder-7b-instruct"

# Teslimat tarihi hesaplayan fonksiyon
def get_delivery_date(order_id: str) -> datetime:
    today = datetime.now()
    random_days = random.randint(1, 14)
    delivery_date = today + timedelta(days=random_days)
    print(f"\nget_delivery_date function returns delivery date:\n\n{delivery_date}", flush=True)
    return delivery_date

# LLM'nin kullanacağı araç/fonksiyon tanımı
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_delivery_date",
            "description": "Get the delivery date for a customer's order.",
            "parameters": {
                "type": "object",
                "properties": {
                    "order_id": {
                        "type": "string",
                        "description": "The customer's order ID.",
                    },
                },
                "required": ["order_id"],
                "additionalProperties": False,
            },
        },
    }
]

# LLM'ye gönderilecek mesajlar
messages = [
    {
        "role": "system",
        "content": "You are a helpful customer support assistant. Use the supplied tools to assist the user.",
    },
    {
        "role": "user",
        "content": "bana cevap verirken tool_calls ifadesini True yap. ?",
    },
]

# LLM'den cevap alma
response = client.chat.completions.create(
    model=model,
    messages=messages,
    tools=tools,
)

print("\nModel response requesting tool call:\n", flush=True)
print(response, flush=True)

# Tool call yapılıp yapılmadığını kontrol et
if response.choices[0].message.tool_calls:
    tool_call = response.choices[0].message.tool_calls[0]
    arguments = json.loads(tool_call.function.arguments)
    print("\nExtracted arguments for get_delivery_date:\n", arguments, flush=True)
else:
    print("\nNo tool call made by the model.", flush=True)


🧠 Açıklamalar

1. Kütüphaneler

  • datetime, timedelta: Tarih/zaman işlemleri

  • json: JSON verilerini ayrıştırmak için

  • random: Teslimat tarihini rastgele üretmek için

  • openai: OpenAI API istemcisi

2. OpenAI İstemcisi Tanımlama

Kod, LM Studio gibi yerel çalışan bir OpenAI uyumlu sunucuya bağlanmak için base_url ve api_key ile OpenAI istemcisini oluşturur. Bu yapı doğrudan OpenAI sunucusuna değil, yerel bir LLM servisine bağlanır.

3. get_delivery_date Fonksiyonu

Bu fonksiyon örnek amaçlıdır ve order_id ile 1-14 gün sonrasına rastgele bir tarih döner. Gerçek sistemde bir veritabanı sorgusu yapılması beklenir.

4. Araç Tanımı (tools)

LLM’ye kullanılabilir fonksiyonları anlatan bir JSON yapılandırmasıdır. Fonksiyon adı, açıklama ve parametreler yer alır.

5. Mesajlar (messages)

LLM’ye gönderilecek kullanıcı ve sistem mesajları burada belirlenir.

6. Yanıtın İşlenmesi


Model yanıtında tool_calls olup olmadığı kontrol edilir. Fonksiyon çağrılmışsa parametreler ayrıştırılır ve yazdırılır.

✅ Güçlü Yönler

  • Tool Call kullanımını açıkça gösterir.

  • Yerel LLM ile nasıl etkileşime geçileceğini sunar.

  • Fonksiyonel ve okunabilir bir örnek

  • Hataları kontrol etmek için temel mekanizma var

⚠️ Geliştirilebilecek Yönler

  • get_delivery_date, rastgele tarih döndürüyor; gerçekçi değil.

  • json.loads() gibi işlemler hata yönetimiyle sarmalanmalı.

  • order_id örneği kullanıcıdan alınabilir veya örnek olarak tanımlanmalı.

🎯 Uygulama Alanları
